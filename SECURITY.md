# Security Policy

## Scope

This repository contains a static website and a Python build script. The GitHub Actions workflow downloads the public Google Sheets XLSX export and publishes generated files to GitHub Pages. The workflow does not require repository secrets.

## Reporting a Vulnerability

Please do not report security vulnerabilities in a public issue. Use GitHub's private vulnerability reporting feature from the repository's **Security** tab. If private reporting is unavailable, contact the repository maintainers privately through GitHub.

Include the affected file or page, steps to reproduce, and potential impact. Please avoid including personal or sensitive data in a report.

This project is maintained on a best-efforts basis; response and remediation times are not guaranteed.
